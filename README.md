## Questions

### 1. What is Version Control?
Version Control is a system that records changes made to files over time. It helps users track, manage, and restore different versions of their work.

### 2. What is Git?
Git is a distributed version control system used to track changes in files and manage source code.

### 3. What is GitHub?
GitHub is an online platform that hosts Git repositories. It allows users to store, share, manage, and collaborate on projects.

### 4. What is Git Bash?
Git Bash is a command-line application that allows users to use Git commands and interact with Git repositories.

### 5. What are the main parts of GitHub?
The main parts of GitHub include repositories, files, branches, commits, pull requests, issues, and the GitHub interface.

### 6. What are the stages of Git/GitHub?
The basic stages are Working Directory, Staging Area, Local Repository, and Remote Repository (GitHub).
